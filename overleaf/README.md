# Sara Reyes - Overleaf CV templates

Each folder is a self-contained Overleaf project (one `main.tex`, compile with pdfLaTeX, the Overleaf default).

| Folder | Style | Length |
|---|---|---|
| `academic/` | Classic serif long-form academic CV: numbered journal/conference/presentation lists, page numbers | 4 pages |
| `modern/` | Sans-serif with blue accent and icons (change the `accent` colour at the top) | 2 pages |
| `onepage/` | Compact one-page resume for industry/internship applications | 1 page |

## Importing into Overleaf
- **Zip upload:** Overleaf > New Project > Upload Project > pick `academic.zip`, `modern.zip` or `onepage.zip`.
- **GitHub sync:** Overleaf > New Project > Import from GitHub, then set the main document to e.g. `overleaf/modern/main.tex`.

`*-preview.pdf` files show what each template compiles to.
